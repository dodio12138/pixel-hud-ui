# Pixel HUD UI 设计规范

一套「飞行计算机 / 复古 HUD」风格的界面框架：像素字体、直角、标题栏色条、1px 线框、CRT 扫描线。
本文规定基础（网格、字号、颜色、动效）和每个控件的结构、尺寸、状态与用法。
实现都在 `assets/pixel-hud.css`，效果见 `assets/demo.html`。

## 设计原则

1. **结构靠线和色条，不靠阴影和圆角。** 所有元素直角、平面；层次来自 1px 线框、标题栏色条和底色深浅。唯一的「投影」是浮层的硬边错位投影。
2. **颜色有固定职责。** 同一种颜色在整个界面里只表达一件事（见[颜色职责](#颜色职责)），用户学一次就能读懂所有屏幕。
3. **选中就是反色。** 被选中、被激活、被悬停的元素用标题栏色填满、文字变深色，像按下了一个发光的键。
4. **信息密度高，但对齐严格。** 控件紧凑，统一落在 4px 网格上；数值右对齐，标签左对齐。
5. **状态永远可见。** 开关、指示灯、仪表条直接显示状态，不只靠文字；不可用的控件变淡但保留形态和颜色。
6. **动效是「步进」的。** 闪烁、加载都用 `steps()` 跳变，不做弹性缓动；颜色变化 100ms 线性过渡。

## 基础

### 网格与间距

基础单位 4px，细节可用 2px。所有尺寸、间距取下表的值。

| 变量 | 值 | 典型用途 |
| --- | --- | --- |
| `--hud-space-1` | 2px | 图标与文字的最小间隙、指示灯内边距 |
| `--hud-space-2` | 4px | 紧凑控件内边距、并排按键间距 |
| `--hud-space-3` | 8px | 控件左右内边距、表单项内部间距 |
| `--hud-space-4` | 12px | 面板内边距、表格单元格 |
| `--hud-space-5` | 16px | 面板之间、表单项之间 |
| `--hud-space-6` | 24px | 区块之间 |
| `--hud-space-7` | 32px | 页面级留白 |

**控件高度**（按键、输入框、下拉、标签页、分段控件统一）：

| 尺寸 | 高度 | 字号 | 类名 |
| --- | --- | --- | --- |
| 小 | 24px | 12px | `.is-sm` |
| 中（默认） | 28px | 14px | — |
| 大 | 32px | 14px | `.is-lg` |

同一行里的控件用同一尺寸。

### 字体与字号

- 界面字体：`--hud-font`（Fusion Pixel 12px 比例宽度，含完整中日韩字形）。
- 等宽字体：`--hud-font-mono`（Fusion Pixel 12px 等宽），用于代码、数值列、按键标识。
- 像素字形画在 12px 网格上，**12px 和 24px 最锐利**；14、16px 用于正文和标题也可以接受。
- 粗体不用字重表达（像素字没有粗体），改用颜色：强调文字 = 绿色。

| 用途 | 变量 | 字号 / 行高 |
| --- | --- | --- |
| 辅助信息、标签、时间戳 | `--hud-text-xs` | 12px / 1.5 |
| 正文、控件文字 | `--hud-text-sm` | 14px / 1.6 |
| 面板标题、小节标题 | `--hud-text-md` | 16px / 1.4 |
| 页面标题 | `--hud-text-lg` | 24px / 1.25 |
| 大数字、展示 | `--hud-text-xl` | 36px / 1.1 |

数字列使用等宽字体并右对齐，便于比较。标题栏文字加 0.06em 字间距。

### 颜色职责

| 变量 | 职责 | 不要用来 |
| --- | --- | --- |
| `--hud-bg` | 页面底色、输入框底色 | — |
| `--hud-panel` | 面板、菜单、对话框底色 | 页面大面积底色 |
| `--hud-hover` | 可交互元素的悬停底色 | 表示选中 |
| `--hud-selected` | 弱选中（多选中的已选项） | 当前项（当前项用反色） |
| `--hud-border` | 1px 线框、分隔线 | 文字 |
| `--hud-text` / `-muted` / `-dim` | 主文字 / 次要文字 / 提示与禁用 | — |
| `--hud-accent` | 链接、标题、可交互强调 | 大面积填充 |
| `--hud-bar` / `--hud-bar-text` | 标题栏、选中项反色、按键悬停 | 正文背景 |
| `--hud-bar-soft` / `--hud-bar-line` | 表头、代码块头的淡色条与分隔线 | 面板标题栏 |
| `--hud-green` | 「开」：指示灯、开关、强调文字、焦点框、光标 | 装饰 |
| `--hud-yellow` | 数值、编号、标签、行内代码 | 警告（警告用橙色） |
| `--hud-orange` | 注释、提示、警告 | 错误 |
| `--hud-red` | 错误、危险操作 | 普通强调 |
| `--hud-info` | 第二种操作色（如「排队」类动作） | 链接 |

规则：**绿色只表示「开 / 成功 / 强调」**。把它用在装饰上，它就不再意味着「开」。

### 边框、层级与投影

- 所有边框 1px，直角。没有圆角（框架会强制 `border-radius: 0`）。
- 层级从低到高：页面 `--hud-bg` → 面板 `--hud-panel` → 浮层（菜单、提示框、对话框、轻提示）。
- 只有浮层有投影：硬边错位投影 `--hud-shadow`（3px 3px，无模糊），像屏幕上叠了一块面板。
- 焦点框：1px 绿色描边，外偏 1px（`:focus-visible`）。永远不要去掉焦点框。

### 图标

- 线性图标，线宽 2px（24 视框下），`stroke-linecap: square`、`stroke-linejoin: miter`，与像素字的方正感一致。
- 尺寸：小 12px、中 14px（默认）、大 16px；与文字并排时间距 `--hud-space-2`。
- 颜色跟随文字（`currentColor`），这样反色时图标一起反色。

### 动效

| 场景 | 方式 | 时长 |
| --- | --- | --- |
| 颜色、边框变化 | `linear` 过渡 | 100ms |
| 开关滑块移动 | `linear` | 120ms |
| 光标、加载块闪烁 | `steps()` 跳变 | 1s 左右一个周期 |
| 浮层出现 | 直接出现，不做淡入缩放 | — |

尊重 `prefers-reduced-motion: reduce`：闪烁和加载动画停止，状态仍然可读。

### 统一的状态模型

所有可交互控件遵循同一套状态，方便用户一眼识别：

| 状态 | 表现 |
| --- | --- |
| 默认 | 线框（或实心色键） |
| 悬停 | 线框键：填满标题栏色、文字反色；实心键：变亮 12% |
| 按下 | 向右下移 1px（像被按下的物理键），实心键变暗 |
| 焦点 | 1px 绿色焦点框 |
| 选中 / 当前 | 标题栏色填满、文字反色；列表行左侧加 3px 绿边 |
| 禁用 | 保持形态和颜色，透明度 0.4，光标 `not-allowed` |
| 加载 | 文字替换为步进闪烁的三个方块，控件不可点击但不变淡 |
| 错误 | 边框变红，下方红色说明文字（以「!」开头） |

**在标题栏色上**（标题栏、选中行）：悬停反色要反过来——深色底、标题栏色文字，否则会和背景融为一体。

## 控件

每个控件说明：结构、尺寸、状态、什么时候用 / 不用、无障碍。

### 面板与标题栏

- 结构：`.hud-panel` 包裹，顶部 `.hud-titlebar`（标题栏色条，深色文字，字间距 0.06em），内容区内边距 `--hud-space-4`。标题栏右侧可放图标键（`.hud-titlebar__actions`）。
- 面板内的小节用 `.hud-subhead`：强调色文字、下方 1px 线，比标题栏安静。
- 用：把一组相关信息框起来，比如「仪表」「轨道」「任务」。
- 不用：表格和代码块的头部不用整条标题栏，用淡色条（见[表格](#表格)）；不要在面板里再嵌一个带标题栏的面板，改用小节标题。
- 无障碍：标题栏文字用真正的标题元素（`h2`/`h3`）或 `aria-labelledby` 关联面板。

### 按键（按钮）

- 线框键 `.hud-btn`：1px 线框，透明底。次要操作。
- 实心键 `.hud-btn.is-solid`：按意图上色，`data-intent`：
  - `accent`（默认）：主操作，强调色；
  - `go`：确认、开始、启用，绿色；
  - `warn`：需要注意的操作（插队、覆盖），黄色深字；
  - `info`：第二类操作（排队、稍后），靛蓝白字；
  - `danger`：删除、停止，红色白字。
- 尺寸：`.is-sm` / 默认 / `.is-lg`。图标在文字左侧。
- 状态：见统一状态模型；加载用 `aria-busy="true"`（文字隐藏，显示步进方块）。
- 用：一个区域只放一个实心主操作；并列的几个操作各用一种意图色，**不可用时保持颜色变淡**，不要变成线框。
- 不用：不要用实心键做导航链接；不要一排全是实心键。
- 无障碍：用 `<button>`；纯图标按钮必须有 `aria-label`。

### 图标键

- `.hud-icon-btn`：正方形，边长等于控件高度（默认 28px），图标 14px。
- 悬停反色；在标题栏、选中行上反过来（深底亮图标）。
- 用：工具栏、标题栏动作、行内操作。
- 无障碍：必须有 `aria-label` 和 `title`。

### 标签页与分段控件

- 标签页：`.hud-tabs > .hud-tab`，当前项 `aria-selected="true"` 反色。用于切换视图。
- 分段控件：`.hud-segmented > button`，按钮紧贴、共用边框，当前项 `aria-pressed="true"` 反色。用于 2–5 个互斥选项（如「1x / 2x / 4x」）。
- 不用：超过 6 个选项改用下拉选择。
- 无障碍：标签页用 `role="tablist"` / `role="tab"`；分段控件用 `aria-pressed`。

### 列表行

- `.hud-row`：一行一个对象（导航项、文件、会话）。悬停浅底；当前项（`aria-current` 或 `aria-selected`）反色并加 3px 绿色左边。
- 行内的图标键在当前行上反向反色。
- 次要信息（时间、数量）用 `--hud-text-dim`，右对齐，等宽数字。

### 表单字段

- 结构：`.hud-field` > `label.hud-label` + 控件 + `.hud-help` 或 `.hud-error`。
- 标签在上方，12px 次要文字色；必填用黄色 `*`。
- 帮助文字 12px 提示色；错误文字 12px 红色，以「!」开头，同时控件边框变红（`aria-invalid="true"`）。
- 多个字段纵向间距 `--hud-space-5`。
- 无障碍：`label` 的 `for` 关联控件；帮助和错误用 `aria-describedby`。

### 文本输入框

- 原生 `input`、`textarea` 在框架内自动是 1px 线框直角样式；聚焦时边框变强调色并加一圈淡光晕。
- 像命令行的大输入框（聊天、搜索、终端）用 `.hud-input` 外框；字段加 `data-pixel-caret` 得到 3px 粗、略高于文字的块状光标（`assets/pixel-caret.js`）。
- 占位文字用提示色。

### 下拉选择

- 原生 `select` 包在 `.hud-select` 里，右侧显示像素下箭头；高度同控件尺寸。
- 选项超过 12 个时加筛选输入（自定义菜单实现）。

### 复选框与单选框

- `.hud-check`（`label` 包 `input[type=checkbox]` + 文字）：14px 方框，选中时内部填满绿色方块。
- `.hud-radio`：同样是方形（这个框架没有圆），选中时内部是更小的绿色方块，用来和复选框区分。
- 不确定状态（部分选中）：内部是一条横线。
- 用：复选框表示独立的是/否；单选框表示一组互斥选项。即时生效的单个设置用开关。

### 开关

- `button.hud-switch[role=switch][aria-checked]` > `.hud-switch__knob`：32×18，像指示灯。开 = 绿色底、深色滑块在右；关 = 面板底、暗色滑块在左。
- 用：立即生效的开/关设置。需要点「保存」才生效的用复选框。

### 滑块

- 原生 `input[type=range]`：刻度式轨道（一格一格），方块滑块头；悬停、拖动时滑块头变绿。
- 旁边用等宽数字显示当前值。

### 仪表条（进度）

- `.hud-gauge`，用 `--value`（0–1）表示进度，像燃料条一样一格一格填满；`data-state="warn"` 变黄，`"alert"` 变红。
- 用：确定进度、容量、剩余量。不确定的等待用[加载](#加载与空状态)。
- 无障碍：加 `role="progressbar"` 与 `aria-valuenow/min/max`。

### 指示灯

- `.hud-lamp[data-state]`：9px 方块灯 + 文字。`on` 绿、`off` 暗、`warn` 黄、`alert` 红。
- 用：系统、连接、任务状态。灯旁边必须有文字，不只靠颜色。

### 数值标签与徽标

- `.hud-tag`：黄色字、淡黄底、黄色细框。用于数值、编号、短代码、参数名。
- `.hud-badge`：标题栏色底的小计数（如未读数），12px，最少 16px 宽。

### 按键标识

- `kbd`（或 `.hud-kbd`）：等宽字体、1px 线框、底边 2px，表示键盘按键，如 `Ctrl` `F5`。

### 菜单

- `.hud-menu`：浮层面板（面板底、1px 线框、硬投影）。项目 `.hud-menu__item`：悬停浅底，当前/勾选项前加 `✓`；快捷键右对齐、提示色；危险项红字；分隔线 `.hud-menu__sep`（虚线）。
- 无障碍：`role="menu"` / `role="menuitem"`，方向键移动，Esc 关闭并把焦点还给触发按钮。

### 提示框

- `.hud-tooltip`：标题栏色底、深色字、12px，无箭头，直角；悬停 400ms 后出现，离开立即消失。
- 只放简短说明；可点击内容放菜单或对话框里。

### 对话框

- `.hud-dialog`：带标题栏的面板 + 硬投影，下方操作区右对齐（次要线框键在左、主要实心键在右）；背后半透明遮罩。
- 多层对话框时，按一次 Esc 只关闭最上层。
- 无障碍：`role="dialog"` + `aria-modal="true"` + `aria-labelledby`；打开时焦点进入，关闭时还给触发者。

### 轻提示

- `.hud-toast`：面板 + 左侧指示灯色条（`data-state` 决定颜色）+ 文字 + 可选操作键；右下角堆叠，4 秒后自动消失（带操作的延长到 8 秒）。
- 只用于不打断用户的结果反馈（「已保存」「已复制」）。需要用户做决定的用对话框。
- 无障碍：容器 `role="status"`（错误用 `role="alert"`）。

### 表格

- `table.hud-table`：1px 外框，行间细线；表头用**淡色条** `--hud-bar-soft`（不是整条标题栏），文字正文色。
- 数字列等宽右对齐；悬停行浅底；选中行反色。

### 代码块

- `.hud-code`：1px 线框；头部 `.hud-code__header` 用淡色条，左边语言名、右边小号线框键（复制）。
- 代码用等宽字体，行号用提示色。

### 正文排版

- `.hud-prose` 包裹渲染后的 Markdown 或文章：标题强调色、一二级标题下方虚线；**粗体显示为绿色**（不加粗）；行内代码黄色标签样式；引用块左侧橙色竖条；列表圆点绿色；表格同 `.hud-table`。

### 加载与空状态

- 加载：`.hud-loader`，三个方块依次点亮（`steps()`）；按钮内加载用 `aria-busy="true"`。
- 空状态：`.hud-empty`，居中、提示色、方括号包裹，如 `[ 没有任务 ]`，下面可放一个线框键作为下一步操作。

### 分隔线与滚动条

- `hr` / `.hud-divider`：1px 虚线，边框色。
- 滚动条：10px 宽，轨道面板色，滑块边框色、悬停变强调色，直角。

## 新建一套配色

1. 先定 `--hud-bg`、`--hud-panel` 和 `--hud-text`（暗色主题：底色很深、文字很亮；亮色主题相反）。
2. `--hud-hover`、`--hud-selected` 在面板色基础上逐级加亮（暗色）或加深（亮色）。
3. 定一个强调色 `--hud-accent` 和它上面的文字色 `--hud-accent-contrast`；标题栏色 `--hud-bar` 默认等于强调色，想要更亮的标题栏就单独设。
4. `--hud-green` 在暗色主题上取「略带灰的绿」，不要用纯荧光绿；亮色主题用深绿。
5. 运行 `node scripts/check-contrast.mjs your.css`，所有 FAIL 都修掉：文字对所有底色 ≥ 4.5:1，边框和绿色对页面底色 ≥ 3:1。

## 无障碍清单

- 所有交互控件都能用 Tab 到达，焦点框清晰可见。
- 颜色不是唯一的信息来源：指示灯、开关、错误都配文字或形状变化。
- 图标按钮有 `aria-label`；开关用 `role="switch"` + `aria-checked`；标签页、菜单、对话框使用对应的 ARIA 角色。
- 文字对比度达标（配色检查脚本）。
- 尊重减少动态效果的系统设置。
